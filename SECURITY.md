# Security Policy

## Supported versions

Only the latest published version of each `@saasontools` package receives
security fixes. Older versions are not patched; upgrade to the latest.

## Reporting a vulnerability

Please report vulnerabilities **privately** via
[GitHub Security Advisories](https://github.com/saasontools/strauss-agent-tools/security/advisories/new).
Do not open a public issue for anything security-sensitive.

Include what you can: affected package and version, reproduction steps, and
impact. API keys handled by these tools (e.g. `GEMINI_API_KEY`) never leave
the user's machine except toward the provider's own API; anything that
violates that is in scope.

## Response

- Acknowledgement within **3 business days**.
- Assessment and severity triage within **7 business days**.
- Fix or mitigation for confirmed issues targeted within **30 days**,
  coordinated disclosure after the fix ships.
