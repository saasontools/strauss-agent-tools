# Support

- **Bugs and feature requests** — use the
  [issue forms](https://github.com/saasontools/strauss-agent-tools/issues/new/choose).
- **Questions and ideas** — use
  [Discussions](https://github.com/saasontools/strauss-agent-tools/discussions).
- **Security issues** — see [SECURITY.md](SECURITY.md); never open a public
  issue for these.

This is an open-source project maintained on a best-effort basis; there is no
commercial support or SLA.
