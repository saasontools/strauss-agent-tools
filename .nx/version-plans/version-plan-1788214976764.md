kb_catalog: tier-one listing and a page-count gate for choosing load vs pack

`kb_load` now also refuses past `maxRecords` (default 40, superseded records excluded), separate from the token budget; the refusal names the gate and points to `kb_catalog` then `kb_pack`. A base of 41+ such records that loaded before now refuses — pass a higher `maxRecords`, `all: true`, or a `type` filter to restore it. New `kb_catalog` (CLI `catalog [type]`) lists every record in one line — id, type, title, standing, stale flag — and never refuses. `kb_load`'s success branch also reports `pageCount`/`maxRecords`; CLI flags now accept `--flag=value` and error on a missing value instead of silently falling back to the default.
