# Changelog

This package was reset to `0.1.0` before its first npm publish, when the
repository adopted "new packages start at `0.1.0`" (see CONTRIBUTING.md).

An earlier release run versioned it to `1.1.0` and produced a git tag and a
GitHub release, but the npm publish never succeeded — no `1.x` of this
package was ever available to install, so nothing downstream depends on those
numbers. Entries below `0.1.0` therefore start again from scratch; the work
they described is unchanged and still in the history.
