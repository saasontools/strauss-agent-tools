## Decision

A generator banner is read from the branch and may lower its own file

## Rationale

SAA-810's precedence puts a generator banner after the base's attributes as something the repository declares. A new generated file has no base copy to read it from.

## Rejected

Read the banner at the base only: every newly generated file would classify source until a second change, and a banner removed on the branch would still lower.

## Impact

A branch can mark a file generated by writing `@generated` into it. The banner sits in the diff the reviewer reads, a base `strauss-class=source` still outranks it, and a local attributes file turns it off. The risk stays open for its reviewer.
